# Sistema Web de Gestión de Inventarios
Sistema web desarrollado para facilitar la administración, seguimiento y análisis de inventarios mediante herramientas de desarrollo web, gestión de bases de datos y análisis predictivo.

Descripción del proyecto
El proyecto consiste en el desarrollo de una plataforma web orientada a centralizar los procesos relacionados con el control de materiales e inventarios. Su propósito es facilitar el registro de movimientos, la administración de solicitudes y la consulta de información para apoyar la toma de decisiones.
La solución integra una interfaz web, un servicio backend, una base de datos relacional y un componente de análisis predictivo.
Este repositorio presenta el proyecto desde una perspectiva técnica y profesional. No contiene el código fuente original ni información interna de la organización para la que fue desarrollado.

Objetivo
Desarrollar un sistema web que permita mejorar el control y seguimiento de inventarios mediante el uso de códigos de barras, almacenamiento estructurado de información y análisis de datos históricos.

Funcionalidades principales
Gestión de inventarios: consulta y administración de materiales y existencias.
Lectura de códigos de barras: identificación de productos mediante escaneo.
Gestión de solicitudes: registro y seguimiento de solicitudes de materiales.
Administración de usuarios: acceso a funcionalidades según el rol asignado.
Historial de movimientos: seguimiento de las operaciones relacionadas con el inventario.
Análisis predictivo: procesamiento de información histórica para identificar tendencias y estimar necesidades de abastecimiento.

Organización de usuarios
El sistema contempla diferentes perfiles de acceso para distribuir las responsabilidades dentro de los procesos de inventario:

-Administrador.

-Ingeniería.

-Almacén.

-Compras.

Cada perfil dispone de funcionalidades relacionadas con sus responsabilidades dentro del sistema.
